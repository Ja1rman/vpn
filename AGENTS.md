# Правила публичной конфигурации

IP-адреса и порты задаются через переменные окружения. В отслеживаемых Git файлах запрещены IP-литералы и числовые значения сетевых портов. Это правило распространяется на код, inventory, шаблоны, тесты, CI, Markdown, диаграммы, URL, комментарии и примеры. Loopback, wildcard, private-сети и зарезервированные адреса для примеров также должны поступать из окружения.

Используйте семантические имена `VPN_*`, например `VPN_ENTRY_ADDRESS`, `VPN_LOOPBACK_IP`, `VPN_VLESS_AUTH_PORT` и `VPN_MTPROTO_PORT`. Для Python используйте общий загрузчик `scripts/vpn_env.py` и его функции `env`, `port`, `expand`, `resolve`, `load_json`. JSON-шаблоны содержат `${VPN_*}`. Реальные значения хранятся в игнорируемом `.local/network-env.json`, передаются через `VPN_ENDPOINTS_JSON` или отдельные переменные окружения. Фактические значения не добавляются в публичные файлы, включая `.env.example`.

При переносе настроек в окружение сохраняйте действующие значения в закрытой конфигурации и прежнюю маршрутизацию. Проверяйте обычные точки входа приложения, генерацию deployment bundle, обработку отсутствующих обязательных переменных и типы подставленных портов. Публичные примеры должны соответствовать реально поддерживаемому загрузчику.

В документации используйте переменные и логические названия служб. Готовые ссылки доступа храните в закрытых access-файлах. В исторических отчётах описывайте узлы и входы по их роли, сохраняя результаты проверок. Версии, даты, HTTP-статусы, права файлов, границы протокольных диапазонов и служебное значение для выделения порта операционной системой сохраняют своё значение. Обязательные имена полей внешних API сохраняйте согласно их официальной схеме.

Перед commit проверяйте весь diff и отслеживаемые файлы на IP-литералы, числовые порты и секреты. Новые адреса и порты сначала добавляйте в закрытую конфигурацию окружения. Пароли, UUID клиентов, ключи, сертификаты, базы, bearer-ссылки и содержимое `.local/` передавайте через защищённое окружение или GitHub Secrets. Секретные значения не должны появляться в логах и публичных артефактах.
