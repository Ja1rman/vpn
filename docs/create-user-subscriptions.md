# Как выдать подписку новому устройству

Создавайте **отдельного клиента x-ui на каждое устройство**. Например, `anna-phone` и `anna-laptop` получат разные UUID и Sub ID, поэтому в мониторинге их трафик будет виден отдельно. Чтобы суммировать его в одном отчёте, назначьте этим клиентам общий псевдоним в закрытом JSON мониторинга по их **числовым ID**. Ссылки устройств при этом остаются разными.

## Обычная подписка

1. В x-ui **входного сервера** откройте **Клиенты → «+»**. Задайте уникальное имя в поле **Email** и оставьте сгенерированные **UUID**, **Sub ID** и пароль. При необходимости укажите срок и лимит трафика.
2. В списке привязанных входов отметьте **VLESS `${VPN_VLESS_AUTH_PORT}`** с пустым `Flow`. Эта привязка включает обычный VLESS и VPN Auto. Также отметьте нужные профили, например **Shadowsocks `${VPN_SS_PORT}`**.
3. Сохраните клиента. В его строке откройте **Информация → Подписка → SUB** и скопируйте `https://${VPN_ENTRY_ADDRESS}:${VPN_SUBSCRIPTION_PORT}/sub/<SubID>`. Импортируйте ссылку на устройство. В обычной подписке привязка `${VPN_VLESS_AUTH_PORT}` автоматически выдаётся как **VLESS TLS `${VPN_STANDARD_TLS_PORT}`**, совместимый с Xray, NekoBox и Hiddify. UUID, порт и TLS-параметры поступают из подписки.

Панель 3.10.0 обычно добавляет нового клиента в работающий Xray через API. При ошибке этого обновления панель может запланировать перезапуск Xray. Подробнее: [клиенты x-ui 3.10.0](https://github.com/MHSanaei/3x-ui/blob/v3.10.0/docs/content/docs/en/config/clients.mdx) и [применение клиента в работающем процессе](https://github.com/MHSanaei/3x-ui/blob/v3.10.0/internal/web/service/client_inbound_apply.go#L555-L598).

## VPN Auto

Скопируйте обычную ссылку и замените порт `${VPN_SUBSCRIPTION_PORT}` на **`${VPN_AUTO_SUBSCRIPTION_PORT}`**, сохранив тот же Sub ID. Импортируйте `https://${VPN_ENTRY_ADDRESS}:${VPN_AUTO_SUBSCRIPTION_PORT}/sub/<SubID>` в VPN-клиент. Подписка автоматически выдаст один профиль **VPN Auto**, когда активный клиент появится в выдаче x-ui для привязки `${VPN_VLESS_AUTH_PORT}`. Для существующих и новых клиентов предпочтителен VLESS с TLS на `${VPN_AUTO_TLS_PUBLIC_PORT}`, с проверкой сертификата по IP, SNI и fingerprint Chrome. Если основной VLESS отсутствует в выдаче, подписка использует прежний источник REALITY. Права и учёт трафика остаются в x-ui.

Для существующего устройства обновите подписку в NekoBox или Hiddify, выберите **VPN Auto** в этой подписке и переподключитесь. Параметры нового VLESS вручную задавать не требуется. Прежний TLS-вход сохранён, но старый сохранённый профиль сам не узнает новый публичный порт без обновления подписки.

Ссылки и QR-коды содержат реквизиты доступа. Передавайте их только владельцу устройства. [Как устроены две подписки](two-subscriptions.md).
