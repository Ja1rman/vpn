# Как выдать подписку новому устройству

Создавайте **отдельного клиента x-ui на каждое устройство**. Например, `anna-phone` и `anna-laptop` получат разные UUID и Sub ID, поэтому в мониторинге их трафик будет виден отдельно. Чтобы суммировать его в одном отчёте, назначьте этим клиентам общий псевдоним в закрытом JSON мониторинга по их **числовым ID**. Ссылки устройств при этом остаются разными.

## Обычная подписка

1. В x-ui **входного сервера** откройте **Клиенты → «+»**. Задайте уникальное имя в поле **Email** и оставьте сгенерированные **UUID**, **Sub ID** и пароль. При необходимости укажите срок и лимит трафика.
2. В списке привязанных входов отметьте нужные существующие порты. Для NekoBox/Hiddify можно начать с **Shadowsocks `53715`**. Если нужен VLESS, добавьте **`33172`** для совместимого Xray-клиента. Чтобы подготовить доступ к VPN Auto, отметьте оба VLESS-входа **`33172` и `46738`** и оставьте `Flow` пустым. `46738` используется для авторизации дополнительного входа; для подключения телефона выбирайте подходящий профиль подписки.
3. Сохраните клиента. В его строке откройте **Информация → Подписка → SUB** и скопируйте `https://212.22.70.156:2096/sub/<SubID>`. Импортируйте ссылку на устройство и проверьте, что выбранный профиль подключается.

Панель 3.10.0 обычно добавляет нового клиента в работающий Xray через API. При ошибке этого обновления панель может запланировать перезапуск Xray. Подробнее: [клиенты x-ui 3.10.0](https://github.com/MHSanaei/3x-ui/blob/v3.10.0/docs/content/docs/en/config/clients.mdx) и [применение клиента в работающем процессе](https://github.com/MHSanaei/3x-ui/blob/v3.10.0/internal/web/service/client_inbound_apply.go#L555-L598).

## VPN Auto

После подключения устройства к VPN Auto его вторая ссылка — `https://212.22.70.156:2097/sub/<SubID>` с **тем же Sub ID**. В NekoBox/Hiddify она выдаёт один профиль **VPN Auto**.

Создание записи в панели само по себе не включает новый UUID на портах `33173` и `33174`. Администратору нужно отдельно проверить доступ нового UUID в работающем Xray, добавить его в оба дополнительных входа **с сохранением всех прежних клиентов**, затем опубликовать профиль `33173` в исходной подписке:

```bash
python3 scripts/vpnctl.py publish-compatible
```

Запускайте эту команду с ноутбука **после** обновления обоих входов: она публикует ссылки, но не меняет список разрешённых UUID. Готовой команды для обновления этих списков без перерыва пока нет. До согласованного обновления выдавайте устройству обычную подписку. Ссылку `2097` передавайте после проверки, что она выдаёт один профиль и он действительно подключается.

Ссылки и QR-коды содержат реквизиты доступа. Передавайте их только владельцу устройства. [Как устроены две подписки](two-subscriptions.md).
