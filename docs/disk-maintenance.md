## Выполненные операции

```bash
# Удаление только архивных журналов старше 30 дней.
sudo journalctl --vacuum-time=30d

# Штатная сборка мусора неиспользуемого BuildKit cache.
# Образы, контейнеры и тома эта команда не удаляет.
sudo docker buildx prune --force --max-used-space=2GB --reserved-space=2GB
```

Новые сборки могут потребовать повторного скачивания или пересборки удалённых кэшированных шагов. Работающие сервисы используют сохранённые образы и данные.

Это разовая очистка. Параметры journald, расписания и Docker daemon не менялись. Массовая очистка `docker system prune`, `image prune`, `volume prune`, удаление каталогов Docker вручную и перезапуски не выполнялись.
