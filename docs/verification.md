Исправленный транспорт добавлен API под новым tag `pool-breeze-reef-hysteria-v2`; прежний handler оставлен до завершения старых сессий.

Физический выход пока один: VLESS и Hysteria используют один NL VPS. Отказ всего этого VPS сейчас пережить нечем; проверка трёх независимых выходов выполнялась на временных локальных процессах. При восстановлении более приоритетного выхода новые соединения возвращаются на него, а существующие живые соединения не разрываются принудительно.
