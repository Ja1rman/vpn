# Использование VPN в Grafana

Откройте [VPN — использование](https://212.22.70.156/grafana/d/vpn-usage/) в существующей Grafana. Выберите подписку и период справа вверху. Дашборд показывает объём отправленных и полученных данных, активные подписки, активные устройства с отдельными профилями, трафик по каждому из них и трафик общих профилей. Подписка или устройство считаются активными, когда за выбранный период вырос счётчик трафика.

Учёт использует счётчики клиентов, сохранённые x-ui на входном сервере. Один клиент может пользоваться обычной подпиской и VPN Auto с тем же профилем, и его объём будет общим. Подключения напрямую к выходному серверу и протоколы без клиентских счётчиков x-ui в этот отчёт не попадают. Сайты, адреса клиентов и идентификаторы устройств не экспортируются. Графики за период доступны с момента установки коллектора, история Prometheus хранится до 15 дней в пределах 1 ГБ.

## Как включить учёт конкретного устройства

1. Выдайте каждому устройству отдельную ссылку с собственными UUID и Sub ID. Например, для одного пользователя создайте `anna-phone` и `anna-laptop`. [Как выдать подписку](create-user-subscriptions.md).
2. С ноутбука зайдите на входной сервер и найдите числовые ID созданных записей. Имена из таблицы используйте локально для сопоставления с клиентами в панели.

   ```bash
   python3 scripts/vpnctl.py ssh
   sudo sqlite3 -readonly /etc/x-ui/x-ui.db 'SELECT id, email FROM clients ORDER BY id;'
   exit
   ```

3. На ноутбуке добавьте записи в `.local/vpn-usage-devices.json`. Одинаковый `subscription` объединяет профили пользователя в отчёте, `device` различает устройства. Используйте короткие псевдонимы без персональных данных. ID в примере условные.

   ```json
   {
     "101": {"subscription": "user-1", "device": "phone"},
     "102": {"subscription": "user-1", "device": "laptop"}
   }
   ```

4. Выполните из каталога проекта на ноутбуке `python3 scripts/vpnctl.py deploy-vpn-usage`. Файл `.local/vpn-usage-devices.json` игнорируется Git и копируется на входной сервер с правами `0600`.

Для профиля с общей ссылкой оставьте запись без сопоставления. Такой профиль виден как `sub-<ID>` и входит в общий трафик. Разбивка по устройствам появляется после назначения индивидуальных профилей и сбора новых данных. При переносе на другой сервер сохраняйте базу x-ui и файл соответствий вместе, поскольку числовые ID берутся из базы. Храните назначенные псевдонимы стабильными, чтобы история осталась под одним именем.

## Обновление коллектора

`python3 scripts/vpnctl.py deploy-vpn-usage` устанавливает или обновляет только коллектор, таймер и дашборд. Коллектор раз в 30 секунд читает базу x-ui в режиме read-only. Node Exporter забирает файл из `/var/lib/vpn-node/textfile`, Grafana подхватывает дашборд в течение 30 секунд. Если локального файла соответствий нет, команда сохраняет установленный на сервере файл. Чтобы удалить все соответствия, передайте локальный файл с `{}`.
